# Waydroid Helper 按键映射指南

## 概述

Waydroid Helper 的按键映射功能可将物理键盘按键和鼠标按钮映射为 Waydroid 内的触摸操作。

## 快速开始

### 打开按键映射界面

1. 启动 Waydroid Helper
2. 在**主页**选项卡中点击 Waydroid 状态行，进入**实例详情**
3. 在**按键映射器**部分点击**打开**按钮
4. 屏幕上将出现透明的按键映射覆盖窗口

### 理解两种模式

按键映射覆盖窗口包含两种模式：

- **编辑模式**（默认）。放置、调整和配置控制组件。
- **映射模式**。将映射的键盘和鼠标输入发送给游戏。

按 `F1` 键在编辑模式和映射模式之间切换。在映射模式下，按 `F12` 键可切换组件显示或透明隐藏。

## 设置按键映射

### 添加组件

![image-20250802235726989](../assets/img/KEY_MAPPING_zh/image-20250802235726989.png)

1. 确认当前处于编辑模式
2. 在空白区域点击鼠标右键，打开组件菜单
3. 选择要添加的组件类型
4. 将组件拖动到游戏界面的目标位置
5. 选中组件后，拖动边框上的控制柄调整大小

### 配置按键绑定

1. 双击任意组件进入按键捕获模式
2. 按下要绑定的键盘按键或鼠标按键
3. 组件上会显示已绑定的按键组合

#### 支持的按键类型

- **键盘按键。** 字母、数字、功能键与修饰键（Ctrl、Alt、Shift）。
- **鼠标按键。** 左键、右键、中键。
- **组合键。** 同时按下的多个按键，例如 Ctrl+A、Alt+Tab。

### 组件详细配置

1. 在编辑模式下选中组件
2. 点击组件右下角的齿轮图标
3. 调整参数后点击**确认**

## 使用按键映射

### 激活映射进行游戏

1. 按 `F1` 切换到映射模式
2. 将游戏窗口置于透明覆盖窗口下方
3. 使用已配置的按键操作游戏
4. 需要调整位置或参数时，按 `F1` 切回编辑模式

## 可用控制组件

### 1. 点击按键

![image-20250802223254952](../assets/img/KEY_MAPPING/image-20250802223254952.png)

将键盘按键或鼠标按钮映射为屏幕指定位置的单次点击。按下物理按键时按下触点，松开物理按键时抬起触点。

- **使用场景。** 菜单按钮与普通点击交互。
- **配置。** 将组件放在目标位置并绑定按键。

### 2. 连击按键

![image-20250802225228249](../assets/img/KEY_MAPPING/image-20250802225228249.png)

在指定位置模拟高频连续点击。

- **使用场景。** 自动攻击与连发动作。
- **操作方式。**
  - **长按连击。** 按住按键期间按设定的**每秒连击次数**持续点击。
  - **按键后连击。** 按下按键后执行固定**连击次数**的点击。

### 3. 准星键

![image-20250802225148255](../assets/img/KEY_MAPPING/image-20250802225148255.png)

锁定鼠标指针并将鼠标移动转换为视角拖拽，常用于 FPS 游戏。添加后请拖动矩形边框，使其匹配游戏内可触发视角旋转的区域。

- **使用场景。** FPS 游戏的视角控制与瞄准。
- **配置。** 调节瞄准移动的**灵敏度**（1 至 100）。

### 4. 攻击/开火按键

![image-20250802224603813](../assets/img/KEY_MAPPING/image-20250802224603813.png)

放置在游戏的攻击或开火按钮位置，在准星键处于瞄准状态时生效。

- **使用场景。** 配合准星键实现 FPS 游戏开火。
- **配置。**
  - **鼠标按键。** 选择模拟开火的鼠标按键（**左键**或**右键**）。
  - **启用拖拽开火。** 开火时由开火按键接管指针锁，使鼠标移动直接拖动开火触点（用于压枪或跟枪）。
  - **水平灵敏度**与**垂直灵敏度。** 分别调整拖拽开火在水平和垂直方向上的移动幅度。

### 5. 方向按键

![image-20250802225040921](../assets/img/KEY_MAPPING/image-20250802225040921.png)

将四个方向按键（默认 W、A、S、D）映射到游戏的虚拟移动轮盘。添加后拖动虚线边框，使蓝色圆框与游戏内虚拟摇杆大小一致。

- **使用场景。** 角色移动控制。
- **默认按键。** W（上）、A（左）、S（下）、D（右）。
- **配置。**
  - **滑动控制。** 模拟从轮盘中心向目标方向滑动。
  - **点击控制。** 直接点击对应方向的触点。

### 6. 技能施法

![image-20250802225814744](../assets/img/KEY_MAPPING/image-20250802225814744.png)

映射角色技能按钮，并通过透视投影将技能方向对准当前鼠标光标位置。拖动虚线边框使其与游戏内技能轮盘范围一致。

- **使用场景。** MOBA 与动作游戏的指向性技能。
- **配置。**
  - **施法半径。** 设置用于透视映射的世界空间地面圆半径。
  - **相机俯仰角**与**垂直视野（FOV）。** 匹配游戏相机的俯仰角与垂直视野角度。
  - **原点 X** 与 **原点 Y。** 设置角色地面原点在屏幕上的水平与垂直位置百分比（0% 至 100%）。
  - **施法时机。** 可选**松开释放**（按住瞄准、松开施放）、**立即释放**（划向目标后自动松开）或**手动释放**（按一次进入瞄准，再按一次施放）。
  - **取消施法。** 启用后会生成**取消施法**组件，将其拖到游戏内的取消施法位置，瞄准时按住该键即可中断施法。

### 7. 右键行走

![image-20250802231156125](../assets/img/KEY_MAPPING/image-20250802231156125.png)

放置在游戏的移动轮盘上：按住拖拽可控制移动方向，单击可自动走向光标所在位置。

- **使用场景。** MOBA 游戏移动控制。
- **默认按键。** 鼠标右键。

### 8. 宏按键

添加宏按键后，点击右下角的齿轮图标打开宏命令编辑器。

- 支持 Ctrl+A、Ctrl+C、Ctrl+V、Ctrl+X、Ctrl+Z、Ctrl+Y 等编辑快捷键。
- 所有宏命令均使用小写字母。
- 设置面板打开期间，直接点击屏幕任意位置即可将该点的 `x,y` 坐标插入编辑器。

#### 触发时机命令

`release_actions` 用于分隔按下阶段与释放阶段的命令。位于 `release_actions` 之前的命令在按下宏按键时执行，位于其后的命令在松开宏按键时执行。

示例：

```
# 宏按键按下时在坐标 (0,0) 按下并保持
# 宏按键松开时在坐标 (0,0) 释放
press 0,0
release_actions
release 0,0
```

#### 单击命令

`click x1,y1 x2,y2...` 点击一个或多个坐标点（同时传入多个坐标可实现多点触控）。支持传入 `mouse` 代表当前鼠标光标坐标。

示例：

```
# 同时点击坐标 (0,0)、(1,1) 和当前鼠标位置
# 等待 100ms，然后点击 (2,2)
click 0,0 1,1 mouse
sleep 100
click 2,2
```

#### 按住、释放与切换命令

- `press x1,y1 x2,y2...` 按住一个或多个坐标点（支持 `mouse`）。
- `release x1,y1 x2,y2...` 释放一个或多个坐标点的按住状态。
- `switch x1,y1 x2,y2...` 在按下与释放状态之间切换指定坐标点。
- `key_press key1,key2...` 模拟按下已绑定到其他组件的按键。
- `key_release key1,key2...` 模拟释放已绑定到其他组件的按键。
- `key_switch key1,key2...` 切换已绑定按键的按下与释放状态。
- `toggle_group group1 | group2` 每次触发时在两个命令组之间交替执行（组内多条命令用 `;` 分隔）。
- `release_all` 释放当前所有按下的按键并取消正在执行的宏状态。

示例：

```
# 同时按住 (0,0) 和 (1,1)，宏按键松开时释放
press 0,0 1,1
release_actions
release 0,0 1,1

# 每次按下宏按键时切换 (0,0) 的触摸状态
switch 0,0
```

```
# 宏按键按住时触发 [A] 键按下，松开时触发 [A] 键释放
key_press a
release_actions
key_release a

# 每次按下宏按键时切换 [A] 键状态
key_switch a
```

#### 等待命令

`sleep duration` 等待指定的毫秒数后继续执行后续命令。

示例：

```
# 点击 (0,0)，等待 1 秒，然后点击 (1,1)
click 0,0
sleep 1000
click 1,1
```

#### 瞄准模式命令

`enter_staring` 与 `exit_staring` 用于进入或退出准星指针锁定模式。例如按住某键临时呼出鼠标指针，松开后恢复视角锁定：

```
exit_staring
release_actions
sleep 50
enter_staring
```

#### 方向按键半径切换命令

- `swipehold_radius x` 将方向按键的滑动半径调整为原始大小的 `x` 倍，可用于切换行走与奔跑速度。
- `swipehold_radius_switch x` 在 `x` 倍半径与 `1` 倍正常半径之间切换。

示例：

```
# 按下时行走，松开时奔跑
swipehold_radius 0.2
release_actions
swipehold_radius 1
```

```
# 每次按下在行走与奔跑之间切换
swipehold_radius_switch 0.5
```
